This guide provides the steps to configure a system for Confidential Computing with NVIDIA Hopper and Blackwell GPUs, from the BIOS through GPU attestation in the guest.
The guide doesn't explain the security model behind each step.
For background, refer to the [NVIDIA Confidential Computing whitepaper](https://images.nvidia.com/aem-dam/en-zz/Solutions/data-center/HCC-Whitepaper-v1.0.pdf).

Complete the following sections in order, or start with the section for your [persona](./index.mdx#personas):

1. [Configuring the Hardware](./deploy-hardware.mdx): Configure the BIOS for TDX or SEV-SNP.
1. [Configuring the Host](./deploy-host.mdx): Prepare the host OS and the hypervisor.
1. [Configuring the GPUs](./deploy-gpu-mode.mdx): Bind the GPUs to VFIO and set the GPU mode.
1. [Creating a Confidential VM](./deploy-create-vm.mdx): Create and launch a CVM with the GPUs attached. Skip this section if you already have a VM orchestration flow.
1. [Configuring the Guest](./deploy-guest.mdx): Install and configure the NVIDIA driver in the CVM.
1. [Attesting the GPU](./deploy-attest.mdx): Verify the configuration, attest the GPU, and enable the GPU to accept work.

## Conventions

In the command examples, lines that start with `$` are commands to run, and lines that start with `#` are comments.
Lines without a prefix are command output.
Some examples omit output that doesn't matter unless the command reports an error.

The host examples store downloads and scripts in the `/shared` directory.
You can use a different directory if you change the paths in the commands.
